## WHAT THIS PROJECT IS
Multi-sport live scores site (football, cricket, F1).
Next.js 14.2.35 (App Router, TypeScript, Tailwind, Turbopack).
Football works with real API. Cricket + F1 are placeholders.

## WHAT WORKS (deployed & live)
1. Home page — live football matches, sport cards. Cricket/F1 = "Coming soon".
2. Football list (/football) — clean cards: league + logo, status, teams + logos + score.
   No inline events. Mobile responsive.
3. Match detail (/football/[id]) — score header, MATCH EVENTS (goals, yellow/red cards,
   subs), LINEUPS & COACHES (formation, coach, starting XI, bench), venue, referee.
   Card icons use INLINE STYLES (not Tailwind) — was a bug fix.
4. PlayerMatchStats.tsx + SeasonStats.tsx exist but NOT currently imported.
